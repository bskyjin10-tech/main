# 📖 세계의 명언 (World Famous Quotes)

동서고금 위인, 철학자, 과학자, 문학가들의 깊은 울림과 영감을 담은 **세계의 명언 프로그램**입니다.
별도의 복잡한 설치 과정 없이 **로컬에서 더블 클릭 한 번으로 즉시 실행**할 수 있습니다.

---

## ✨ 주요 기능

1. **엄선된 동서고금 세계 명언 115선**
   - 소크라테스, 니체, 괴테, 아인슈타인, 스티브 잡스, 헬렌 켈러, 생텍쥐페리, 공자, 부처 등
   - 품격 있는 한국어 번역 및 원문(영문/원어) 병기, 인물 소개 및 태그 제공
2. **오늘의 명언 (Quote of the Day)**
   - 날짜를 기반으로 매일 새로운 대표 명언 제시
3. **랜덤 명언 생성기 (Dice)**
   - 버튼 클릭 시 새로운 명언을 무작위로 추천
4. **6대 카테고리 필터링**
   - 🌱 인생과 삶 | 🚀 성공과 도전 | 💡 지혜와 배움 | 🔥 용기와 희망 | 💖 사랑과 관계 | ☀️ 행복과 마음
5. **실시간 검색**
   - 명언 본문, 인물 이름, 키워드/태그(#습관, #독서 등) 실시간 검색
6. **즐겨찾기 (북마크)**
   - 마음에 드는 명언의 하트 아이콘을 눌러 나만의 보관함에 저장 (브라우저 로컬 저장소)
7. **고화질 명언 카드 이미지 저장 (PNG 다운로드)**
   - 예쁜 그라디언트 배경과 텍스트가 담긴 고화질 명언 카드 이미지를 원클릭으로 다운로드하여 SNS나 메신저에 공유
8. **음성 낭독 (TTS)**
   - 웹 브라우저 음성 합성 기능을 통해 명언을 감미로운 목소리로 낭독
9. **클립보드 원클릭 복사**
   - 깔끔한 인용 서식으로 명언 텍스트 복사
10. **3가지 감성 테마**
    - ☀️ 라이트 모드 | 🌙 다크 모드 | 🌅 선셋 감성 모드

---

## 🚀 로컬 실행 방법

### 방법 1. 원클릭 더블클릭 실행 (가장 추천 ⭐)
- 폴더에 있는 **`실행하기.bat`** 파일을 마우스로 더블 클릭합니다.
- 또는 **`index.html`** 파일을 더블 클릭하여 크롬, 엣지(Edge) 등 브라우저로 바로 실행합니다.
> **인터넷 연결이나 별도 프로그램 설치 없이 100% 로컬 환경에서 즉시 동작합니다.**

### 방법 2. 파이썬 터미널 모드 (선택 사항)
- 파이썬이 설치되어 있는 경우:
  - **`터미널_실행.bat`** 더블 클릭 또는
  - 터미널에서 `python main.py` 실행

---

## 📂 파일 구성 안내

- `실행하기.bat` : 원클릭 프로그램 실행 배치 파일
- `index.html` : 세계의 명언 웹 애플리케이션 메인 화면
- `style.css` : 감성 글래스모피즘 & 테마 스타일시트
- `app.js` : 명언 추천, 검색, 필터, 음성 낭독, 이미지 저장 등 핵심 인터랙션 로직
- `quotes.js` : 115편의 세계 명언 데이터베이스 (JavaScript)
- `quotes.json` : 세계 명언 데이터베이스 (JSON 포맷)
- `main.py` : 파이썬 콘솔 터미널용 대화형 명언 프로그램
- `터미널_실행.bat` : 파이썬 콘솔 실행 배치 파일
- `README.md` : 프로그램 안내 및 사용법 설명서
